05SFT 与 RL 的差距

SFT 是 likelihood 基线：4h、lr 1e-4、全层 LoRA，chrF 28.6、QE 13.10。RL 最好的一条是 reference reward + 全层 attention，chrF 20.0、QE 7.38。两者的差距主要落在 chrF。

chrF++：SFT vs 最好 RL vs 从 SFT 再跑 DAPO
QE：同样四组（越低越好）
从 SFT 出发再训练，chrF 的去向

从 SFT 再跑 DAPO，chrF 从 28.6 降到 5.1（QE reward）或 16.6（reference reward）；QE 从 13.10 变成 10.59 / 11.84。SFT 的权重保留了下来，翻译质量没有被保留。

07训练动力学

下面六个量来自同一批 JSONL，颜色仍然对应 run；每个小图只画一个指标，别再和 reward 混在一起看。

reward = 1 − MetricX/25（越高越好）
entropy（nats，越低越确定，塌到 0.1 以下基本没救）
grad norm（裁剪后的总梯度范数）
reward std（组内，接近 0 = 没有信号）
gate pass（非空/长度/script 全过的比例）
sec / step（越低越快，反映生成长度）

共同趋势：reward 升、entropy 降；grad norm 在 1–3 之间抖动；ref reward run 的 entropy 掉得更慢，但 chrF 并没有更高——说明“稳”不等于“翻译好”。
